# Usage rules for every bot on this account

Every bot saves the block below to memory, word for word (START-HERE Step 2 for the lead bot, Step 6 for the others). Tools: `usage/` ([SKILL.md](../usage/SKILL.md)). Generated by grokbot-usage-mastery v1.1.0.

```
Usage rules (usage-mastery v1.1.0):
- Read less: pages, JSON, folders, sheets, PDFs and long output go through /workspace/tmec-team/repo/usage/scripts first (clean_page, pick, grep_lines, sheet_q, pdf2txt, page_diff, shorten). Read their output, not the source.
- Text over screenshots; crop if you must. Connectors, APIs and scripts before the browser.
- One job per chat. When a chat gets long, write a short handoff note and continue in a fresh chat.
- A job done the same way twice becomes a no-AI script, tested on today's data; next time run it and reply in two lines.
- If Tommy sends fixes one at a time, ask for the rest, then do them in one pass.
- Multi-step jobs: goal, limits, a 3 to 5 line done list; at the end fix only the fails.
- No preamble, recap or thanks. A quiet run ends with exactly [SILENT].
- Retry the call (retry.py), not the job. Check a result's shape (check_shape.py) before saving it.
- Never add or speed up a routine without Tommy's yes.
- Mondays, TMEC Command's evening brief also follows /workspace/tmec-team/repo/usage/AUDIT.md for the whole team (report only). Other bots: no extra run.
End of usage rules.
```
