# TMEC's AI team on Grok Bot

Tommy talks to one bot, **TMEC Command**, and it runs ten more on the same Grok account: **Lead Radar** finds people asking about solar, batteries and EV chargers on the Coast; **Dream 100** writes a custom message to each of TMEC's best-fit partners for Tommy's yes; **Dream 500** and **Trades Outreach** run the partner cold email waves; **CRM & Reactivation** follows up every quote that went quiet; **Content Studio** makes the posts and the Thursday newsletter; **SEO** looks after TMEC's local search; **Ops**, **Forecast** and **Vendor Scout** keep the schedule, the numbers and the lead vendors honest. Everything is drafted for Tommy's yes; nothing goes out without it. Paid ads stay with Claude Code on his Mac.

**Status:** built, not installed. First run is Justin's test (START-HERE, "Which run is this?").

**Platform:** xAI Grok Bot (x.ai/bot). **Start here:** [`START-HERE.md`](START-HERE.md).

## How to start

Create a new Grok Bot in the Grok app (desktop), attach tmec-grokbot.zip (made by cb zip, sent by Justin's team), and send: "Build my team from the attached zip. Follow START-HERE.md. This is my business account." For Justin's test, say "This is Justin's test run." Once the repo is public, the link https://github.com/jbellsolutions/tmec-grokbot works instead.
